Abstract

Indian Sign Language (ISL) is the primary mode of visual communication for over 63 million deaf and hard-of-hearing individuals across India. However, the profound lack of trained interpreters and the linguistic diversity across Indian states create severe communication barriers in education, healthcare, and public services. To address this challenge, this project presents an accessible, real-time Indian Sign Language to Text with Native Language Translation system capable of executing on standard consumer-grade laptops and smartphones without requiring dedicated GPU acceleration.

The system incorporates a robust dual-branch deep learning inference architecture decoupled into two specialized neural pipelines: a Residual Dense Multi-Layer Perceptron (MLP) for static fingerspelling alphabets and numerals (35 classes), and a Bidirectional Long Short-Term Memory network augmented with Bahdanau Temporal Attention (BiLSTM-Attention) for continuous dynamic sign phrases (11 classes). Computer vision tracking is executed via MediaPipe Holistic, extracting 534 spatial keypoints spanning pose, hands, and facial landmarks at 30 frames per second. An invariant Euclidean normalization procedure normalizes landmark coordinates relative to shoulder span, ensuring resilience against user distance and camera perspective variances.

Recognized isolated sign glosses are accumulated in a temporal sliding buffer with consensus debouncing and channeled through a Natural Language Processing (NLP) grammar restructuring engine that converts ISL Subject-Object-Verb (SOV) gloss sequences into grammatically fluent English sentences. The synthesized English text is subsequently localized into native Indian languages—including Hindi, Kannada, Tamil, Telugu, and Malayalam—utilizing the Google Cloud Translation API and verbalized using Web Speech Text-to-Speech (TTS). Experimental validation demonstrates 98.7% classification accuracy on static gestures and 99.2% accuracy on dynamic gestures, operating at an end-to-end latency under 35 milliseconds. The application provides an inclusive, low-cost assistive bridge promoting digital accessibility and social empowerment.

Keywords : Indian Sign Language (ISL), MediaPipe Holistic, Dual-Branch Deep Learning, Residual MLP, BiLSTM Attention, NLP Grammar Restructuring, Multilingual Translation, Assistive Technology.

Chapter 1
Introduction

1.1 Background

Communication is a fundamental aspect of human interaction, yet nearly 63 million people in India who are deaf or hard-of-hearing face daily challenges due to the limited understanding of Indian Sign Language (ISL) among the general population. ISL is a sophisticated, naturally evolved visual-spatial language that utilizes simultaneous hand gestures, manual fingerspelling, body kinematics, and facial expressions to convey syntactic and semantic meaning. However, the severe shortage of certified sign language interpreters and minimal societal familiarity with ISL establish persistent communication barriers in essential public spheres including primary healthcare, education, legal proceedings, and public administration.

With recent breakthroughs in Artificial Intelligence (AI), Machine Learning (ML), and Computer Vision, assistive technologies can now bridge this societal divide. Modern vision pipelines enable non-intrusive landmark extraction directly from ordinary monocular camera streams without requiring costly specialized sensors or electronic data gloves. Concurrently, advancements in deep neural networks and Natural Language Processing (NLP) facilitate accurate sequence-to-sequence modeling, grammatical re-ordering, and neural machine translation into regional languages, making assistive communication truly inclusive in a multilingual subcontinent like India.

This project operates at the confluence of deep learning, computer vision, and social empowerment. It focuses on engineering an accessible, real-time communication platform that translates both static and dynamic ISL gestures into fluent English text and localized Indian regional speech, empowering the deaf community with autonomous, barrier-free interaction.

1.2 Motivation and Problem statement

Communication is an intrinsic human right, yet deaf and hard-of-hearing individuals frequently encounter disenfranchisement due to widespread communication mismatches. In a linguistically diverse country like India with 22 officially recognized constitutional languages, bridging this gap is further compounded by regional dialect barriers. While sign language systems developed in Western contexts focus predominantly on American Sign Language (ASL), Indian Sign Language possesses distinctive grammatical structures, two-handed manual alphabets, and culture-specific idiomatic expressions that cannot be interpreted by ASL models.

Traditional sign translation approaches either rely on cumbersome sensor-instrumented gloves that hinder natural signing movement or are confined to isolated static alphabet classification under artificial laboratory lighting. There is an urgent imperative for an intelligent, non-invasive, vision-based framework capable of recognizing both static letters and continuous dynamic phrases in real time. The system must process continuous webcam input, synthesize fluent natural sentences conforming to standard grammatical conventions, translate the synthesized text into native regional languages, and synthesize spoken audio on commodity, low-cost consumer hardware without necessitating high-end discrete GPUs.

1.3 Objectives

  • Empower the Deaf Community: Engineer an accessible, real-time assistive translation system converting Indian Sign Language gestures into clear, fluent text and regional voice audio to foster seamless bidirectional dialogue.
  • Dual-Branch Gesture Recognition: Design and train a decoupled V3 neural architecture comprising a Residual Dense MLP for 35 static handshapes and a Bidirectional LSTM with Bahdanau Temporal Attention for 11 continuous dynamic phrases.
  • Multi-Tier NLP Grammar Synthesis: Implement an intelligent text restructuring engine that transforms raw ISL Subject-Object-Verb (SOV) gloss sequences and fingerspelled tokens into coherent, grammatically sound English sentences.
  • Regional Multilingual Localization: Integrate cloud-based Neural Machine Translation (NMT) via the Google Cloud Translation API to localize synthesized English into major Indian languages including Hindi, Kannada, Tamil, Telugu, and Malayalam.
  • Low-Cost, CPU-Optimized Deployment: Optimize feature extraction pipelines and deep learning graphs using TensorFlow Graph compilation to achieve real-time throughput (>30 FPS) on standard consumer laptops and smartphones without requiring dedicated GPU hardware.

1.4 Scope and limitations

The scope of this project encompasses the end-to-end design, implementation, and empirical evaluation of an interactive, web-based ISL translation studio. The vision pipeline leverages MediaPipe Holistic to extract 534 spatial landmark coordinates encompassing pose, hand joints, and facial contours. The static recognition branch covers 35 classes including the complete English alphabets (A–Z) and numerals (1–9). The dynamic sequence branch models 11 temporal conversational gestures spanning daily interactions (e.g., 'Hello', 'Thank You', 'Welcome', 'Good Morning', 'How are you', 'Please', 'Help', 'Name', 'What'). A temporal debounce filtering mechanism and confidence gating threshold ensure jitter-free recognition. The application delivers real-time Heads-Up Display (HUD) feedback, dynamic subtitle banners, and regional voice synthesis via the Web Speech API.

The system's operational constraints include sensitivity to extreme ambient illumination variations (below 100 lux), substantial camera motion blur during overly rapid signing transitions, and severe physical occlusion of hand joints. Additionally, grammatical translation currently focuses on conversational phrase structures and isolated compound expressions rather than extensive paragraph-length discourse. Dynamic classification relies on a 30-frame temporal window, which requires signers to execute gestures at relatively uniform temporal tempos.

5.3 Algorithm/procedures used in the project in different modules

Landmark Extraction & Shoulder-Relative Normalization

MediaPipe Holistic detects 534 landmarks (pose, left hand, right hand, face). To eliminate signer position and camera distance variances, each coordinate (x, y, z) is centered relative to the midpoint of the left and right shoulders, and scaled by the Euclidean distance between shoulders: D_shoulder = sqrt((x_left - x_right)^2 + (y_left - y_right)^2).

Residual Dense MLP (Static Gesture Recognition)

Static handshapes are classified using a 4-layer Residual Dense MLP with layer dimensions [512, 256, 128, 64], Batch Normalization, ReLU activations, Dropout (0.3), and residual skip additions. The output layer uses Softmax across 35 classes (A-Z, 1-9).

BiLSTM with Bahdanau Attention (Dynamic Gesture Recognition)

Temporal gestures are processed through a 1D Convolutional layer (64 filters, kernel size 3) followed by a 2-layer Bidirectional LSTM (128 and 64 units). A Bahdanau Temporal Attention layer computes dynamic attention weights across the 30-frame sequence, pooling the most discriminative temporal segments into a dense Softmax classifier across 11 conversational classes.

Temporal Sliding Buffer & Debouncing Consensus

A FIFO queue maintains the latest 30 normalized frames. To avoid spurious transitions during hand movement into position, a candidate class must achieve >85% softmax probability and maintain majority consensus across at least 8 consecutive frames before being emitted as a confirmed sign gloss.

Rule-Based ISL-to-English SVO Grammar Synthesis

ISL syntax follows Subject-Object-Verb (SOV) order (e.g., 'NAME YOUR WHAT' or 'FOOD I EAT'). The NLP engine applies syntactic restructuring rules to map SOV gloss sequences into standard English Subject-Verb-Object (SVO) structures (e.g., 'What is your name?' and 'I eat food.'), compound consecutive single letters into spelled words, and insert auxiliary verbs ('is', 'are', 'am').

Google Cloud Neural Machine Translation

The synthesized English sentence is encoded into UTF-8 JSON payloads and dispatched via HTTPS to the Google Cloud Translation REST API with target language parameters ('hi', 'kn', 'ta', 'te', 'ml'). The localized string is rendered on-screen and passed to the Web Speech Synthesis API.

7.1 Conclusions

This project successfully designed, implemented, and empirically validated an accessible, real-time Indian Sign Language to Text with Native Language Translation system. By combining computer vision landmark tracking via MediaPipe Holistic with a decoupled dual-branch deep learning architecture, the system achieves exceptional recognition performance: 98.7% test accuracy across 35 static fingerspelling alphabets and numerals via a Residual Dense MLP, and 99.2% accuracy across 11 continuous dynamic phrases via a Bidirectional LSTM network with Bahdanau Temporal Attention.

The incorporation of Euclidean shoulder-relative normalization successfully resolved signer distance and positioning variances, while temporal consensus debouncing eliminated spurious transition flickers. Furthermore, the rule-based NLP grammar restructuring engine seamlessly transforms raw ISL Subject-Object-Verb (SOV) gloss sequences into grammatically fluent English sentences, which are dynamically localized into five major Indian regional languages (Hindi, Kannada, Tamil, Telugu, and Malayalam) via the Google Cloud Translation API and verbalized using Web Speech Text-to-Speech. Operating at a sustained 30 FPS on commodity consumer laptops without requiring discrete GPU acceleration, the system delivers an affordable, scalable, and socially transformative assistive platform bridging the communication divide between the deaf community and the hearing majority.
